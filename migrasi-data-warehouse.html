Data Engineering Migrasi Big Data

Migrasi Data Warehouse
ke Platform Terdistribusi

Migrasi end-to-end dari data warehouse on-premise yang sudah usang ke platform Big Data terdistribusi menggunakan Hadoop dan Hive — memungkinkan skalabilitas horizontal dan analitik skala besar untuk perusahaan FMCG nasional.

Latar Belakang

Perusahaan FMCG (OT Group) mengoperasikan data warehouse monolitik yang tidak lagi mampu menangani volume data dari operasi distribusi nasional. Sistem memproses data dari lebih dari 10.000 agen penjualan di seluruh Indonesia, mengakibatkan query timeout, kegagalan batch malam hari, dan ketidakmampuan mendukung keputusan bisnis secara real-time. Biaya penyimpanan juga terus meningkat seiring keterbatasan skalabilitas RDBMS konvensional.

Solusi

Memimpin migrasi dari RDBMS konvensional ke ekosistem Hadoop, dengan Hive sebagai lapisan query terdistribusi dan Dremio sebagai platform akses data lake. Migrasi dilakukan secara bertahap untuk memastikan operasional bisnis tidak terganggu selama proses berlangsung.

  • Strategi migrasi bertahap: parallel run → cutover → decommission
  • Implementasi Hive partitioning dan bucketing untuk optimasi performa query
  • Deployment Dremio sebagai self-service data lake engine untuk tim analis bisnis
  • Pembangunan pipeline otomatis untuk kalkulasi insentif menggantikan proses Excel manual
  • Integrasi Apache Spark untuk workload agregasi data yang kompleks

Teknologi yang Digunakan

Hadoop (HDFS)
Apache Hive
Apache Spark
Dremio
Apache ZooKeeper
Python
