Data Engineering Migrasi Big Data

Migrasi Data Warehouse
ke Platform Terdistribusi

Migrasi end-to-end dari data warehouse on-premise berbasis Sybase ke platform Big Data terdistribusi menggunakan Hadoop dan Hive — memungkinkan skalabilitas horizontal dan analitik real-time untuk klien multifinance enterprise di PT. Adicipta Inovasi Teknologi.

Latar Belakang

Klien multifinance di PT. Adicipta Inovasi Teknologi (AdIns) mengoperasikan data warehouse monolitik berbasis Sybase yang tidak lagi mampu menangani pertumbuhan volume data transaksi pembiayaan. Sistem mengalami query timeout pada jam sibuk, kegagalan batch malam hari, dan tidak mampu mendukung kebutuhan analitik real-time. Skalabilitas vertikal RDBMS konvensional sudah mencapai batasnya, sementara volume data terus bertumbuh seiring ekspansi portofolio klien.

Solusi

Memimpin migrasi dari Sybase ke ekosistem Hadoop, dengan Hive sebagai lapisan query terdistribusi dan Dremio sebagai platform akses data lake untuk tim analis. Migrasi dilakukan secara bertahap dengan strategi parallel run untuk memastikan zero downtime pada operasional bisnis klien.

  • Strategi migrasi bertahap: parallel run → validasi data → cutover → decommission
  • Implementasi Hive partitioning dan bucketing untuk optimasi performa query pelaporan multifinance
  • Deployment Dremio sebagai self-service data lake engine untuk tim analis bisnis klien
  • Migrasi pipeline ETL dari SSIS ke Spark job untuk workload agregasi data yang kompleks
  • Pembangunan lapisan data mart baru untuk kebutuhan pelaporan regulasi OJK

Teknologi yang Digunakan

Apache Hive
