Data Warehouse Migration
to Distributed Platform

End-to-end migration of a legacy on-premise data warehouse to a distributed Big Data platform using Hadoop and Hive, enabling horizontal scalability and real-time analytics for a large-scale FMCG enterprise.

Problem

An FMCG enterprise (OT Group) was operating a monolithic data warehouse that could no longer handle the growing data volume from nationwide distribution operations. The system processed data from 10,000+ sales agents across Indonesia, resulting in query timeouts, overnight batch failures, and inability to support real-time business decisions. Storage costs were also escalating with traditional RDBMS scaling.

Solution

Led the migration from a traditional RDBMS-based warehouse to a Hadoop ecosystem, introducing Hive as the distributed query layer and Dremio as the data lake access platform. The migration was executed in phases to ensure zero downtime for business operations.

  • Phased migration strategy: parallel run → cutover → decommission
  • Implemented Hive partitioning and bucketing for optimized query performance
  • Deployed Dremio as a self-service data lake engine for business analysts
  • Built automated incentive calculation pipelines replacing manual Excel processes
  • Integrated Apache Spark for complex aggregation workloads
