Data Engineering Hybrid Cloud ML Pipeline

Arsitektur Data Hybrid
dengan Pipeline ML Scoring

Perancangan platform data hybrid yang menghubungkan infrastruktur on-premise dengan cloud, terintegrasi dengan pipeline machine learning untuk collection scoring — meningkatkan efisiensi operasional penagihan pada perusahaan multifinance.

Latar Belakang

Klien multifinance membutuhkan modernisasi operasional penagihan dengan menghadirkan kemampuan prediktif berbasis machine learning. Sistem yang ada tidak memiliki kapabilitas ML sama sekali, dan tim collection sepenuhnya bergantung pada prioritisasi manual. Selain itu, infrastruktur data yang terfragmentasi — data transaksional on-premise tidak dapat terhubung langsung ke layanan ML berbasis cloud — menciptakan kesenjangan antara tim data engineering dan data science.

Solusi

Merancang arsitektur hybrid yang menjembatani SQL Server on-premise dengan GCP untuk pelatihan dan inferensi model ML. Apache Airflow digunakan sebagai lapisan orkestrasi terpusat yang mengelola perpindahan data, jadwal retraining model, dan pengiriman hasil scoring kembali ke sistem operasional.

  • Pipeline hybrid: SQL Server on-premise → GCP BigQuery → model ML → hasil scoring
  • Deployment Airflow DAG untuk orkestrasi dan penjadwalan pipeline end-to-end
  • Implementasi model collection scoring dengan retraining otomatis setiap minggu
  • Framework automated unit testing menggunakan Spark dan Python
  • Dashboard real-time di Apache Superset dan Power BI untuk monitoring tim collection

Teknologi yang Digunakan
