Data Engineering Hybrid Cloud ML Pipeline

Hybrid Data Architecture
with ML Scoring Pipeline

Architecting a hybrid on-premise and cloud data platform for a multifinance company, integrating machine learning collection scoring pipelines with Apache Airflow orchestration to improve debt recovery operations.

Problem

A multifinance client needed to modernize their collection operations by introducing predictive scoring for debtors. The existing system had no ML capability, and collection teams relied entirely on manual prioritization. Additionally, the data infrastructure was siloed — on-premise transactional data could not be easily connected to cloud-based ML services, creating a gap between data engineering and data science teams.

Solution

Designed a hybrid architecture bridging on-premise SQL Server data warehouse with GCP for ML model training and inference. Apache Airflow was deployed as the central orchestration layer, managing data movement, model retraining schedules, and scoring result delivery back to operational systems.

  • Built hybrid data pipeline: on-premise SQL Server → GCP BigQuery → ML model → scoring results
  • Deployed Apache Airflow DAGs for end-to-end pipeline orchestration and scheduling
  • Implemented collection scoring model with automated weekly retraining
  • Automated unit testing framework using Spark and Python — reduced testing time by 40%
  • Built real-time dashboards in Apache Superset and Power BI for collection team monitoring
