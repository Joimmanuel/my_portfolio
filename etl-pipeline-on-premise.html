Data Engineering ETL On-Premise

On-Premise ETL Pipeline
& Data Warehouse

Designing and implementing a scalable on-premise ETL pipeline — migrating legacy reporting systems to a modern 3-layer SQL Server data warehouse, orchestrated with SSIS and visualized through Power BI.

Background

The existing reporting system relied on a legacy database with no proper data warehouse layer. Reports were generated manually, taking 2–3 days to produce, with frequent data inconsistencies across departments. The system could not scale to handle growing transaction volumes, and there was no centralized source of truth for business decision-making.

Approach

Designed and implemented a full on-premise ETL pipeline using SQL Server as the data warehouse target and SSIS as the orchestration layer. The architecture introduced a 3-layer data model — Staging → ODS → Data Mart — ensuring clean data separation, lineage traceability, and reliable incremental loading.

  • Automated daily ETL jobs replacing manual report generation workflows
  • Incremental load strategy to efficiently handle 500K+ daily transaction records
  • SSAS multidimensional cubes for MDX-based analytical queries
  • SSRS dashboards for operational and executive-level reporting
  • Data quality checks and error logging at every pipeline stage

Tech Stack

SQL Server 2019
SSIS
SSAS (MDX)
SSRS
Power BI
Sybase (Source)

Outcome

2–3 Days Report generation time reduced to minutes
500K+ Daily records processed reliably with full consistency
3-Layer Clean data architecture: Staging → ODS → Data Mart
